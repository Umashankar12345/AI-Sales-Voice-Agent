## 2. Summary of Forensic Findings
1. **Genuinely Implemented & Verified**: Groq LPU inference, Deepgram Aura TTS (`HTTP 200`), LiveKit JWT minting, BANT + 0–100 scoring, Sentiment analysis, Semantic RAG (`all-MiniLM-L6-v2` + FAISS + upload/delete/dedup/isolation), Cross-call MongoDB memory, Atomic Appointment booking + 5-way race protection + `.ics` export, MongoDB CRM + CSV export, and Backend Auth/RBAC (`auth.py`).
2. **Hardcoded / Disconnected**:
   - `frontend/src/pages/AnalyticsPage.jsx` lines 45–51 has a **hardcoded** `courses` breakdown array (`count: 12, pct: 35`, etc.) instead of `stats.course_distribution`.
   - `frontend/src/pages/VoiceAgentPage.jsx` uses browser Web Speech API only and **does not call** `/api/voice/turn` (Deepgram) or `/api/voice/livekit-token` (LiveKit).
   - `backend/app/auth.py` `get_optional_user` allows unauthenticated access to `"org_default"` because the React frontend has no login screen yet.
3. **Not Implemented / Untestable Without Credentials**:
   - LiveKit `voice-agent` worker process (no worker running in this repo).
   - Live Google Calendar OAuth sync (only `.ics` export exists).
   - Live HubSpot CRM sync (`HUBSPOT_ACCESS_TOKEN` not configured).
   - Dedicated Hindi TTS audio output verification.
